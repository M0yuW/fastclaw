# Stage 2A confirmatory attempt status

Date: 2026-10-10. The project-report frozen study was started against an isolated copy of the local FastClaw Gateway configuration. The existing Gateway on port 18953 and its database were not modified. External DeepSeek use was explicitly authorized with a USD 10 cumulative estimated-cost cap.

The run is **paused and incomplete**, not a completed confirmatory experiment. Two of 24 case batches were executed. Their retained reports and hash manifests contain 18/216 planned primary observations and 4 diagnostic observations. No all-Pro ablation observation was run. Both primary errors were `team_raw_context` request deadlines in `FRET-NVDA-POINT-MEDIUM` repetitions 1 and 3. The baseline primary error rate is 2/18 = 11.1%, exceeding the frozen protocol's 5% pause threshold; including diagnostics gives 2/22 = 9.1%, also above threshold. The runner stopped before starting the third case.

The completed-call telemetry records USD 0.171053 for the two formal batches. Two preflight calibration calls, excluded from formal analysis, record USD 0.013258, giving USD 0.184311 in recorded estimated cost. These amounts are **lower bounds**, not a reliable billed total: the two timed-out HTTP requests have no completed-call telemetry, although their upstream model calls may have incurred charges. The USD 10 guard was not approached.

The isolated Gateway session records explain the timeouts more specifically than the HTTP error alone. For the two errored raw-context repetitions, each of seven successive `spawn_subagent` calls contained invalid, cut-off JSON arguments of roughly 24.8–25.1 thousand characters. The tool surfaced `agentId is required` and the model retried until the client deadline. In repetition 2, one valid tool-call argument of 16,355 characters was accepted and the observation completed. This points to oversized raw-context tool arguments exhausting the model response capacity; it is an observed failure mechanism, not proof of the precise provider-side token limit. No frozen prompt, grader, source lock, agent source, or completed report was altered during the run.

The manifest utility initially rejected error observations with no provider telemetry. Its post-run validation was corrected to preserve such assigned, errored observations while still rejecting a supposedly successful observation with missing telemetry. This changes only artifact handling, not the frozen executable or model treatment. The raw medium-case report was not rerun or edited; its manifest was created after the validator correction. The 11 artifact tests pass. A checkpoint analysis with `--allow-incomplete` was generated, but its comparison estimates are not suitable as study conclusions.

Before resumption, the oversized delegation problem needs an engineering correction and a new study version if the correction changes the frozen treatment. A same-version continuation is permissible only if the intervention does not change the treatment and the protocol's pause/resumption conditions are met. The two timed-out attempts must remain visible; they cannot be silently replaced by reruns.
