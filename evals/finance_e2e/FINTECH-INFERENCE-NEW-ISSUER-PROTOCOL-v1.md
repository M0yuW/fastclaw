# Prospective new-issuer FinTech inference panel (v1)

## Status and question

This numbered protocol was written before any model observation in this panel. On 2026-10-23, the six official SEC Exhibit 99.1 files linked in `fintech_inference_new_issuer_v1.json` were cached, byte-hashed, and checked against all 38 selected fact-row anchors. The separate source audit records file lengths, hashes, period/column checks and limits. Source and rubric criteria are now frozen before the first call. The runner must still pass its fail-closed preflight and hash the corpus, runner, source files, template database, Gateway binary, plugin, prompt and rubric into a new manifest before sending any model request. Never backfill source hashes after model output.

SOURCE-FROZEN-BEFORE-MODEL: yes

The question is whether the current agent runtime can repeatedly produce **source-bounded, decision-useful financial interpretations**, not merely execute tools or restate facts. The three issuers (Affirm, SoFi, Upstart) have not appeared in the earlier finance panels. All tasks use historical disclosures available by 2024-11-07; later filings, prices and returns are out of scope. The selected packet is narrower than the full SEC exhibit, and the agent must not pretend to have reviewed omitted facts.

## Cases and ex ante interpretation checks

1. **AFRM-FISCAL-COST:** compare FY2024 Q4 with FY2025 Q1, respecting the fiscal-year rollover. Revenue rises while RLTC (non-GAAP) and adjusted operating income fall and GAAP operating loss deepens. Transaction costs, credit-loss provision and funding costs rise. The model may describe the arithmetic and identify questions about credit/funding economics, but must not infer a deterioration of realized credit quality or a complete causal bridge from the selected fields.
2. **SOFI-REVENUE-BRIDGE:** compare calendar 2024 Q2/Q3. Q3 GAAP net revenue is USD 697.121 million and adjusted net revenue is USD 689.445 million; the disclosed bridge is `697,121 - 4,362 + 9 - 3,323 = 689,445` (USD thousand). GAAP net income also rises sequentially. Keep GAAP and non-GAAP labels distinct and do not attribute all profit improvement to a particular segment without a supported segment-to-consolidated bridge.
3. **UPST-MIXED-BASIS:** compare calendar 2024 Q2/Q3 and keep the Q3 year-over-year comparatives separate. Q3 revenue, contribution profit, GAAP net loss and adjusted EBITDA improve sequentially; nevertheless Q3 GAAP operating loss and adjusted net loss are worse than their Q3 2023 comparators. Q3 GAAP net loss includes a USD 33.361 million gain on debt extinguishment; a narrower net loss is not wholly operating improvement. A blanket claim of GAAP profitability or uniformly improved profitability is wrong. The non-GAAP contribution metric is not itself earnings.

No prompt may prescribe an action, conviction level, `needs_review` label or favorable thesis. The agent must propose a research implication, strongest counterpoint or unresolved input, and evidence that would change its view; its final prose and persisted state are judged separately. A correctly cautious conclusion can score high if it is specific and decision-useful, but generic abstention that conceals a provable comparison cannot.

## Planned execution

- Existing SEC-event-to-thesis workflow, three issuer clusters, five fresh Gateway/session/ledger repetitions each: **15 planned observations**. Fixed Flash model and pricing, source packet, prompt, finance plugin, policy, template DB, Gateway binary, tool-iteration and output-token limits. Randomized order with recorded seed; no replacement run or after-output tuning.
- Preflight all six raw SEC files: exact SEC URL and Exhibit 99.1 identity, byte count, SHA-256, selected fact/period/unit checks, and arithmetic checks. The two Affirm HTML exhibits are under 100 KB; exact hashes and row anchors, not a generic large-file threshold, establish this packet's integrity. The case packet and source files must be included in a pre-run manifest. A source discrepancy requires a new numbered revision before any paid run; do not edit this frozen v1 in place after observations exist.
- The packet's `statement_line` field uses the finance plugin's **causal-driver taxonomy**, not a literal financial-statement row name: aggregate operating income/net income use `unknown`, and Upstart's debt-extinguishment gain uses `nonoperating`. A free isolated plugin-ingest rehearsal with sentinel hashes has passed for all three cases; it validates input shape only and is never evidence of source provenance. The real run requires the six SEC source hashes and fail-closed selected-fact preflight to pass again.
- A free lineage unit check confirms that the Upstart debt gain is line-compatible with a cautious net-income interpretation but **not** with an operating-margin explanation; the guard also rejects a numerical attribution lacking a reconciled bridge. This protects structured ledger claims only. It does not inspect or guarantee the agent's final prose, which must still receive claim-level review.
- For each observation, retain the full model/tool trace, retrieved source identifiers, initial thesis, final answer, guarded review, alert acknowledgement, ledger snapshot, runtime errors, usage and priced cost estimate. Any request error, unpriced usage or cost uncertainty stops the arm and remains in the denominator. The arm cap is USD 0.10 estimated model spend, subordinate to the user's USD 10 outer authorization; reserve USD 0.02 before starting the next observation. Do not overwrite prior result directories.
- Hash raw result files before judgment. Deterministic execution checks and F/I/R/S/U content scores use the existing `INSIGHT-QUALITY-JUDGE-RUBRIC-v1.md`. Record claim-level source pointers for every material 0/1 or critical error. Codex is a non-blind, non-independent first-pass judge, not a finance expert. Repeated answers to one case are correlated.
- The pre-run `FINTECH-INFERENCE-CLAIM-GATE-v1.json` freezes five common and three issuer-specific claim checks per observation. After the run, `prepare_fintech_inference_claim_review_v1.py` verifies retained result hashes and emits an **unscored** 8-check worksheet per observation. A reviewer fills PASS/FAIL/NOT_ASSESSABLE and evidence pointers using both final prose and persisted state. This worksheet complements, rather than replaces, the F/I/R/S/U high-quality rubric; no checker or automatic count can silently award `high_within_case`.

## Predeclared gate and claim boundary

Within this panel: 15/15 mechanically complete, all material figures and period/basis comparisons correct, no critical unsupported fact or causal claim, and at least 4/5 `high_within_case` in **each** issuer cluster. Report cluster counts and exact failure modes even if the gate fails. Passing would support repeatable quality in these three selected SEC event-to-thesis cases only. It would not prove profitability, predictive value or stable high-quality insight across all finance workflows. The broader runtime objective still requires separate prospective real-source screening and portfolio-risk evidence plus, when available, an independent blinded domain review.
