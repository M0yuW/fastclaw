The Gateway reached its eight-tool-iteration limit and returned a partial final response. Source packets and linked evidence were intact, and the tool did not accept the malformed calls. The failure is a workflow-completion and agent tool-argument/recovery failure under the present eight-iteration budget, not proof of source-data or calculation corruption. It should not be counted as a pass merely because two review rows exist.

Together with the separate conflict run, the four workflow types have eight Flash observations, seven mechanically passing. This is a small selected feasibility panel, not a population reliability estimate or a statistically meaningful model comparison. Source/value checks here verify the *stored event packets* against frozen inputs, not independent parsing of the underlying SEC pages. The successful W03/W04 cases use deterministic synthetic tools. The panel supports a bounded runtime claim: the same authenticated Gateway, policy-filtered finance tools, tenant-isolated ledger, correlated trace, and usage attribution execute across several financial-research workflows, while a failed long-form turn remains auditable rather than silently counted as success.
