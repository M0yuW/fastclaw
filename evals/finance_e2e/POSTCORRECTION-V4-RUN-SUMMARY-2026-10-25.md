It now returns a retriable `malformed_review_payload` error when review fields such as `evidence` or `next_review_at` are visibly serialized inside `rationale` rather than supplied as top-level arguments. The finance-tools unit suite passes 26/26, including a test that the malformed write leaves no review and a corrected top-level write persists a held review. These changes do **not** retroactively repair TFC-r2 or the three state/prose contradictions in the v4 frozen results.
